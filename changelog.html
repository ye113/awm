更新日志

每个版本的改动都记在这里。新版本发布前，先更新本页再发公告。

2026-11-28 v0.1.9

全新界面与授权码判定修复

  • 优化界面改版第一期：整体换成「玫瑰金 iOS」暗色风格，菜单、开关、滑块、卡片等控件统一视觉，页面间距与字号重新对齐
  • 优化参数市场卡片布局调整：「详情 / 下载 / 兑换」与作者工具按钮的位置更统一，付费参数一眼可辨
  • 修复修复在别人的付费参数上填自己的授权码会提示「兑换成功」的问题：现在会提示「该授权码不属于这个参数」，并且不会消耗这张码
  • 修复兑换成功后自动下载的，一定是这张授权码对应的参数，不会再下成当前打开的那一条
  • 修复从页面底部「兑换授权码」输入仍按通用方式兑换（码属于哪个参数，就兑换并下载哪个）
2026-11-25 v0.1.8

参数市场支持付费参数

  • 新增参数市场支持付费参数：作者可把自己的参数设为「私人（付费）」，只有持有授权码的人才能使用
  • 新增作者可为自己的付费参数生成授权码（一次最多 5 个，一码一机），并把授权码发给买家
  • 新增买家在参数市场输入授权码，即可下载并使用对应的付费参数
  • 新增作者可在「我上传的」里查看自己参数的授权情况（谁在用、是否有效）
  • 优化云端参数只在使用时生效，不在本地保存；关闭客户端后不再残留
  • 优化付费参数在使用期间为只读（数值隐藏、不可修改、不可导出），点「重置」即可恢复为本地参数
  • 优化左右飞抑制按武器分别管理：应用某个武器的方案，不会影响其它武器的左右飞设置
  • 优化参数市场界面优化：作者工具按钮调整到卡片右侧，生成授权码后自动复制到剪贴板
  • 修复修复应用云端方案后「启用预测」无法关闭的问题
  • 修复修复付费参数在同步后显示的距离段数量与本机不一致的问题
2026-11-23 v0.1.7

目标锁定、近战秒蓄、追踪与界面优化

  • 新增自瞄新增「目标锁定」：锁定一个目标后不再来回切换，目标离开范围 / 超出距离或失效时才重新选择；可在自瞄 → 基础设置里勾选
  • 新增武器功能新增「近战秒蓄」：缩短近战武器的蓄力时间，需对局内且身上带有对应武器（对当前携带的武器生效）
  • 新增「范围增强」新增快捷键开关：在武器功能下方的「范围增强设置」里绑定按键，按一下即可快速开 / 关
  • 新增绘制新增「追踪」：输入名称关键词（支持中文、可添加多条），被追踪的物资 / 怪物始终单独高亮显示，不受分类、价值与距离过滤影响；追踪颜色可在「自定义设置」中调整
  • 新增实用功能新增「自动开门」：对局内自动开启附近的普通门 / 树门，可设范围、间隔与开关热键
  • 新增实用功能新增「自动拾取」：对局内自动拾取附近的道具与回收物（需背包有空位），可设范围、间隔、拾取类别与开关热键
  • 优化怪物白名单改为标签式展示：点击标签即可移出名单，条目较多时自动滚动
  • 修复私密方案保护改为按武器 / 范围独立：同步一份新的私密方案，不会再把其它武器此前已锁定的私密状态覆盖或解除
2026-11-23 v0.1.6

玩家列表状态、显示与自瞄优化

  • 新增玩家列表新增「状态」列：存活 / 死亡 / 撤离，一眼可见
  • 新增玩家列表支持自定义「面板宽度」与「装备图片大小」
  • 优化左右飞抑制可按武器分别设置：猎枪 / 左轮 / 狙击各调各的抑制力度，以前调好的需在各武器页签重新设置
  • 优化玩家列表「背包物资」现在把腰包 / 额外背包里的物品一并统计（容器本身也算）
  • 优化「服务状态」提示改为黄色提醒、文案更简洁（部分功能可能受限），不再让人误以为服务器故障
  • 优化对局列表：普通物品（含回收物）改为按价值四档上色
  • 修复个别设备异常不再被当成「全服维护」提示，其他用户不受影响
  • 修复对局列表去掉行尾与物品重复的「喷包 / 枪械」计数
  • 修复无图标的物品不再在前面留空位
