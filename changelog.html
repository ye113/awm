更新日志

每个版本的改动都记在这里。新版本发布前，先更新本页再发公告。

2026-11-12 v0.0.8

人物信息面板角色头像

  • 新增人物信息面板新增角色头像：头像显示在队伍标记左侧，一眼看出对面是哪个角色
  • 新增角色阵亡时显示对应的灰色头像，与存活状态一眼区分
  • 新增新增「角色头像」开关与「头像大小」调节（16~72，默认 40）；关闭头像后，名字前会显示角色名，信息不丢
  • 新增自瞄新增「切换静默」「切换路飞」快捷键，一键切换瞄准方式
  • 新增自瞄相关快捷键统一收进可折叠的「快捷键设置」，默认收起，不占版面
  • 优化人物信息面板排版对齐：头像 / 队伍标记 / 名字与血量 / 血条与体力条 / 距离，列宽更紧凑，多个面板并排时不易互相遮挡
  • 优化切换瞄准方式、开关自瞄时，右下角有提示，随时知道当前状态
  • 修复适配游戏最新版本，角色状态、物品与地图相关显示恢复正常
2026-11-12 v0.0.7

机器码识别修复

  • 优化设备识别更稳定：重装系统、重装程序、更换安装目录后，仍会被识别为同一台设备
  • 修复修复部分用户设备码重复，多人同时使用时互相挤下线、玩到一半客户端突然消失的问题
  • 修复修复更新日志弹窗与「概览」页在部分屏幕尺寸与缩放下排版异常（文字截断、弹窗过窄或超出屏幕），条目较多时可在窗口内滚动查看
2026-11-12 v0.0.6

更新日志 · 修复与优化

  • 新增更新日志弹窗：新版本首次打开菜单时展示本版更新内容，可勾选「本期不再显示」
  • 新增「概览」页新增常驻更新日志，随时可回看当前版本内容
  • 新增网络或登录异常时，屏幕顶部会给出清晰提示，方便截图反馈
  • 优化更新日志按「新增 / 优化 / 修复 / 安全」分类展示，版本与日期一目了然
  • 优化在大厅等待进入对局时不再退出，改为后台等待并提示，进入对局后自动恢复
  • 优化异常与恢复状态更清晰，方便截图反馈
  • 优化同行标记改为面板下方独立小徽章，不再挤占名称、不撑大面板
  • 修复参数市场私密方案：同步设置后重新打开程序，数值仍保持隐藏与锁定，不再变回可编辑
2026-11-12 v0.0.5

同行标记 · 官网改版

  • 新增同行标记：客户端与 ESP 同步显示同行徽标
  • 新增上线更新日志页，后续版本改动集中在这里维护
  • 优化参数市场私密方案下，左右飞抑制等快捷键仍由本机自行设置，不再被隐藏
  • 优化官网全面改版：赛博霓虹配色、两栏首页、实机截图首屏
2026-11-11 v0.0.4

参数市场上线

  • 新增自瞄参数市场：可上传 / 下载他人的自瞄参数，一键套用到本机
  • 新增公开 / 私密两种分享方式；私密方案数值自动隐藏，不可修改、不可导出
  • 优化新增下载量统计，以及「我上传的 / 我的下载」统一管理
